# AI Usage Declaration

## 1. Purpose

This document declares the use of AI tools during the preparation of the Smart CRM – Warranty Claim Intake project.

## 2. AI Tools Used

- Tool: ChatGPT
- Purpose: Assistance with document organization, requirement analysis, technical explanations, and reviewing draft content.

## 3. Scope of AI Assistance

AI assistance may include:
- Suggesting an initial SRS structure.
- Explaining Use Case, architecture, ERD, and SQL DDL concepts.
- Reviewing consistency between project documents.
- Providing examples of documentation and SQL statements.

## 4. Human Review and Responsibility

The project team is responsible for reviewing, verifying, editing, and approving all submitted materials. AI-generated suggestions are not treated as verified facts without review.

## 5. Declaration

This declaration describes the actual use of AI tools for the project. Any additional tools, prompts, or contributions should be documented accurately where required by the course.
